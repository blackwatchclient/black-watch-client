# Alpha roadmap

[Back to Black Watch](../README.md)

## 1. Prepare the first test release

Connect the project's own Microsoft application registration to the Minecraft Services review process. Validate sign-in with an eligible Minecraft: Java Edition account, profile retrieval, token renewal, first-run setup and the Windows launch path. Prepare a reproducible client build and clear participation information.

## 2. Test with alpha participants

Evaluate normal gameplay, interface usability, HUD layouts, profile handling and cosmetics. Gather reproducible bug reports and compare performance on different computers under comparable conditions. Preserve visual quality while investigating unnecessary CPU work, GPU work and memory allocation.

## 3. Refine through beta

Resolve high-impact problems found during alpha, expand compatibility checks and improve onboarding and reliability. Move to broader testing when the earlier feedback supports it.

## 4. Public release

Publish a stable client after successful alpha and beta testing. Continue maintenance and develop additional features and cosmetics based on player feedback.

These are development milestones, not fixed dates or guaranteed performance results. The project is currently preparing for alpha; this repository does not contain a public client download.
